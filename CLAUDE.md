# Правила проекта
- Дизайн — в GDD.md. Не переобсуждать решённое; новые решения коротко дописывать туда.
- Стек: Phaser 3.80.1 локально в lib/ (без CDN, для офлайна на Android), ES-модули, без сборщика. Код в src/.
- Одна сессия = одна задача. Не читать весь проект без нужды.
- Тексты игры: через словарь RU/EN (src/i18n.js), не хардкодить.
- Графика: силуэты, рисуем кодом простыми фигурами или CC0-ассеты в assets/.
- Мобильный экран в приоритете: landscape, тап-управление.
- Деплой: push в ветку → GitHub Pages (workflow pages.yml).
