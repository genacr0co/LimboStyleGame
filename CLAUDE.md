# Правила проекта
- Дизайн — в GDD.md. Не переобсуждать решённое; новые решения коротко дописывать туда.
- Стек: Three.js 0.170.0 локально в lib/ (без CDN — для офлайна на Android), ES-модули + importmap, без сборщика. Код в src/.
- Игра 3D, но геймплей в плоскости z = 0 (2.5D, как Little Nightmares / Inside). Глубина — реальные слои по z + туман.
- Одна сессия = одна задача. Не читать весь проект без нужды.
- Тексты игры: только через словарь RU/EN (src/i18n.js), не хардкодить.
- Графика: силуэты из простых 3D-фигур кодом (общий тёмный материал, туман делает даль светлее). Ассеты — только CC0 в assets/.
- Управление без видимого UI: жесты (см. src/input.js). Мобильный landscape в приоритете.
- Деплой: push в ветку → GitHub Pages (.github/workflows/pages.yml). Android-билд — позже (Capacitor).
